## 적용 방법

1. 압축을 푼 무수정 원본의 크기·MD5·CRC32 또는 SHA-256이 위 표와 일치하는지 확인합니다.
2. 아래 해당 패치를 원본에 **한 번만** 적용하고 결과를 별도 파일로 저장합니다.
3. 적용 후 결과 크기와 체크섬을 다음 표와 대조합니다.

IPS 지원 도구에서 원본과 **r39 IPS**를 선택합니다. IPS는 원본 해시를 자체 확인하지 않으므로 위 원본 확인이 필요합니다. 과거 r35~r38을 먼저 적용하지 않습니다.

이미 한글화된 ROM에 덧씌우지 않습니다. 원본과 기존 저장 파일은 백업하고, 저장 호환성은 아래 기존 안내의 해당 버전 설명을 따릅니다. 버전이 다른 즉시저장 대신 게임 내 이어하기를 사용하세요.

현재 권장 배포판은 r39다. r35~r38은 과거 비교용으로 보존한다. 각 IPS는 동일한 일본어 원본에 직접 적용한다. r35→r36→r37→r38→r39 순서로 중복 적용하지 않는다. 과거 WIP542 계열과 v0.4의 r 번호는 별도 체계여서 합산하지 않는다.
